User Guide & Reference

PromptTest Studio Documentation

Comprehensive guide to authoring plain-English tests, inspecting Android UI elements, running test suites, and managing visual baselines.

1. Overview & Architecture

PromptTest Studio is a visual desktop application built for Android QA teams, developers, and product managers. It bridges physical Android hardware with an intuitive test execution engine via ADB (Android Debug Bridge).

Key pillars of the Studio architecture:

  • Direct Canvas Mirror: Real-time screen capture and input injection without modifying your Android APK.
  • Zero-Instrumented Inspector: Reads native accessibility hierarchies directly via ADB, allowing inspection of third-party apps, system apps, and webviews.
  • Plain-English Execution Engine: Translates natural language instructions into precise UI interactions with automatic fuzzy element resolution.

2. Plain-English Spec Language Reference

PromptTest specs are stored as clean plain-text files. The engine interprets natural verbs and element names without complex code:

Application Control

# Launch an app by package name or display label
Launch "com.example.shopping"

# Close or restart the active application
Terminate "com.example.shopping"
Restart "com.example.shopping"

Touch & Interaction Commands

# Tap on an element by visible text, content description, or resource ID
Tap "Sign In"
Tap "btn_checkout"

# Long press on an element
Long press "Profile Avatar"

# Type text into an input field
Type "alex@company.com" into "Email address"
Type "secure_pass_123" into "Password field"

# Clear an input field
Clear "Search bar"

Assertions & Verifications

# Assert element presence
Assert "Welcome back, Alex" is visible
Assert "Order Placed Successfully" is visible

# Assert negative state
Assert "Error message" is not visible

# Assert checkbox or toggle states
Assert "Remember me" is checked

Navigation & Gestures

# Scroll screen vertically or horizontally
Scroll down
Scroll up
Swipe left

# Hardware navigation buttons
Press Back
Press Home
Press Recents

# Explicit timing waits (if needed)
Wait 2 seconds

3. Visual Element Inspector

When you hover over the live phone canvas in Studio, the Element Inspector overlays a boundary box around the target control. Clicking an element reveals:

  • Display Text & Content Description: The human-readable string used for plain-English steps.
  • Resource ID: Native Android identifier (e.g. com.example:id/login_button).
  • Coordinates & Dimensions: Precise screen bounds (x, y, width, height).
  • Interaction Flags: Whether the element is clickable, focusable, scrollable, or editable.

4. Visual Baseline Comparisons

PromptTest Studio includes visual regression detection. When a visual baseline step is added, Studio captures a pristine screenshot of the screen. On subsequent test runs:

  • The screen is captured at identical resolution.
  • Studio compares the current screen against the reference baseline pixel-by-pixel.
  • Masks: You can drag bounding boxes over fluctuating areas (like digital clocks, Wi-Fi signal meters, and dynamic banners) to exclude them from comparison.

5. Untethered Testing over Wi-Fi (Wireless ADB)

PromptTest Studio supports full untethered device testing over your local 2.4 GHz or 5 GHz Wi-Fi network. Both physical device controls and live streaming operate without an attached USB cable.

Device-Side Setup

  • Android 11, 12, 13, and 14+: Connect phone and PC to the same Wi-Fi. Go to Settings > Developer options > Wireless debugging and toggle on. Tap Pair device with pairing code to reveal your 6-digit PIN, IP address, and port.
  • Android 10 and Older: Connect via USB cable once and execute adb tcpip 5555. Then disconnect the USB cable and locate your device's IP under Settings > About phone > Status.

Studio-Side Connection

  • In the Studio top toolbar, click the Device Selector dropdown and choose "Connect Device over Wi-Fi".
  • Enter the IP address, port, and 6-digit pairing code shown on your Android device.
  • Click Connect. The Studio device badge turns green and live mirroring activates instantly.

6. Troubleshooting & Installation FAQ

Windows SmartScreen: "Windows protected your PC"

Because PromptTest Studio is an independent community application, Windows Defender SmartScreen may display an initial warning on first launch. To proceed: click "More info", then click "Run anyway". The installer is 100% safe, verified, and local-first.

Device shows "Unauthorized" in Studio

Unlock your Android phone, look for the dialog titled "Allow USB debugging?", check the box "Always allow from this computer", and tap Allow.

Studio does not detect the device

  • Verify your USB cable supports data transfer (some charging cables do not include data lines).
  • Ensure USB Connection Mode on your phone is set to File Transfer / MTP rather than "Charge only".
  • Run adb kill-server && adb start-server in PowerShell to reset the local ADB daemon.
