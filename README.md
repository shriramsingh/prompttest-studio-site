# PromptTest Studio Site

Public product website and distribution hub for PromptTest Studio.

## Pages

- Home: `index.html`
- Features: `features.html`
- Getting Started: `getting-started.html`
- Downloads: `downloads.html`
- Docs: `studio.html`
- Changelog: `changelog.html`
- FAQ: `faq.html`
- Contact / Community: `contact.html`

The desktop application source and internal engineering documentation are maintained in a private repository. This repository contains the public marketing site, user guides, and release distribution links.

## GitHub Pages

Deployments are automated on push to `main` via GitHub Actions (`.github/workflows/deploy-pages.yml`):

`https://shriramsingh.github.io/prompttest-studio-site/`

## Media

Add public screenshots to `assets/screenshots/`, GIFs to `assets/gifs/`, and video files or embed links to `assets/videos/`. Avoid putting secrets or private application source code in this repository.
