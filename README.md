# PromptTest Studio Site

Public product website and distribution hub for PromptTest Studio.

## Pages

- Home: `index.html`
- Features: `features.html`
- Getting started: `getting-started.html`
- Downloads: `downloads.html`
- FAQ: `faq.html`
- Contact: `contact.html`

The application source is kept in the private
[`prompttest-studio`](https://github.com/shriramsingh/prompttest-studio) repository.
This repository contains only public marketing content and release links.

## GitHub Pages

Enable **Settings → Pages → GitHub Actions**. The workflow deploys the site at:

`https://shriramsingh.github.io/prompttest-studio-site/`

## Media

Add public screenshots to `assets/screenshots/`, GIFs to `assets/gifs/`, and
video files or embed links to `assets/videos/`. Avoid putting secrets or private
application source code in this repository.
