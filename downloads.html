System Requirements

• Operating System: Windows 10 (1809+) or Windows 11 64-bit

• Permissions: Standard user (No Administrator access required)

Device Compatibility

• Any physical Android phone or tablet running Android 7.0+
• Official Android Studio Virtual Devices (AVD)
• Cloud/local emulators supporting ADB (Genymotion, BlueStacks)
• USB cable or 2.4/5 GHz local Wi-Fi connection

Verify Installer Integrity (SHA-256)

You can verify your downloaded installer in Windows PowerShell using the command below:

Get-FileHash -Algorithm SHA256 "PromptTest Studio_0.1.0_x64-setup.exe"

Compare the output hash against the official hash in our Changelog page or on GitHub Releases ↗.
