v0.2.1 Latest Release Desktop IDE Multi-Platform October 8, 2026

Multi-Platform Engine Auto-Discovery & Release Collision Guard

PromptTest Studio v0.2.1 delivers cross-platform engine binary discovery across Windows, macOS, and Linux workstations. Fixes background engine process handling, expands loopback CORS security, and adds strict version collision protection to the autonomous CI/CD release pipeline.

✨ Features & Capabilities
  • Cross-Platform Engine Candidate Resolution: Studio now automatically scans platform-specific candidate locations (bin/win32, bin/darwin, bin/linux) and system PATH to discover bundled or standalone PromptTest engine executables seamlessly.
  • Automated Release Collision Guards: Release scripts (trigger-release.mjs, publish-public-release.mjs) and the GitHub Actions pipeline now verify tag and release existence beforehand to prevent accidental overwrites or workflow conflicts.
  • Dynamic Desktop Build Matrix: Unified multi-platform build workflow compiling x64 Windows NSIS setups, Apple Silicon aarch64 DMGs, and Linux amd64 AppImage / Debian packages in parallel.
⚡ Engine & Device Connectivity
  • Process Lock & EBUSY Guard: Resolved Windows file lock issues when starting or stopping the background companion engine process during rapid test iterations.
  • Loopback CORS & Doctor Security: Restricted local test engine RPC requests to safe loopback origins with enhanced health preflight checks.
  • Physical Device ADB Routing: Streamlined device canvas mirroring and element inspection on modern Android 14 & 15 physical hardware.
🔒 Integrity & Verification
  • Every build artifact is cryptographically hashed with SHA-256 and verified through automated preflight post-build validation.
  • Published alongside release-manifest.json containing source commit, build timestamp, and architecture metadata.

v0.2.0 Stable October 7, 2026

Initial Multi-Platform Release (Windows, macOS, Linux)

Expanded PromptTest Studio from Windows-only to a full three-tier operating system architecture supporting macOS Apple Silicon and Linux distributions.

✨ Features & Highlights
  • Apple Silicon Support: Added native ARM64 .dmg builds optimized for Apple M1, M2, M3, and M4 Macs.
  • Universal Linux Packaging: Introduced standalone .AppImage binaries compatible with Ubuntu, Debian, Fedora, Arch, and elementary OS alongside .deb package files.
  • Consolidated Release Pipeline: Multi-runner matrix compiling artifacts across GitHub Actions macOS, Ubuntu, and Windows runners.

v0.1.0 Initial Release September 23, 2026

Initial Public Desktop IDE Release

First standalone preview release of PromptTest Studio for Windows 10 and 11 workstations, featuring the live device canvas, visual element inspector, and local test recorder.

✨ Highlights
  • Live Device Mirroring: Real-time screen streaming over standard Android Debug Bridge (ADB).
  • Element Inspector: Point-and-click UI hierarchy inspection generating plain English assertions.
  • Local Test Studio: Zero cloud dependency—all test specs, screenshots, and logs stored 100% locally.
