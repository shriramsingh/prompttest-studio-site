Version 0.1.0

Latest Release · Sep 23, 2026

Initial public release of PromptTest Studio for Windows, featuring the visual desktop IDE, real-time screen canvas, native element inspector, and plain-English test engine.

✨ What's New in v0.1.0

  • Interactive Live Canvas: Real-time Android screen mirroring over ADB with mouse interaction (click, swipe, type) and hardware navigation buttons (Back, Home, Recents).
  • Native Element Inspector: Hover-to-inspect UI hierarchy for Android apps. Instantly exposes resource IDs, accessibility labels, element bounds, and clickable states.
  • Click-to-Prompt Test Authoring: Click any native element on the mirrored device screen to auto-generate readable Tap, Type, and Assert test steps.
  • Real-Time Execution Stream: Live Server-Sent Events (SSE) telemetry displaying step durations, live execution status, and pass/fail diagnostics.
  • Visual Baselines: Screenshot capture and pixel-by-pixel regression comparison with dynamic exclude masks.
  • Device Manager: Auto-detection of connected USB and local Wi-Fi ADB devices with one-click screen wake and unlock.
