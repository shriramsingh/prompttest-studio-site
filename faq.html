Questions, answered

Frequently asked
questions.

Does PromptTest Studio run online?

No. Studio is a local Windows desktop application. GitHub is used only to distribute the installer and documentation.

What devices are supported?

Android devices accessible through USB or Wi-Fi ADB are supported. Keep USB debugging enabled and authorize the computer.

Do I need a custom domain?

No. The public product site runs on the free github.io address.

Where can I report a problem?

Use the contact page and include the app version, Windows version, device model, and relevant steps.
